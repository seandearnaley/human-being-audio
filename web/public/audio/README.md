# Catalogue audio examples

The three-second stereo examples are captured from the production 1.0/2.0 engines at 48 kHz and a 64-frame host block, peak-calibrated to −3.0 dBFS with a 15 ms tail fade-out and encoded as stripped 16-bit 48 kHz stereo FLAC (`-compression_level 12 -map_metadata -1`). Playback is opt-in.

- `livecut-redux.flac` — Livecut Redux 2.0 running a synthetic breakbeat drum loop through the `Rush` pad (`research/gain/`).
- `tract-form.flac` — Tract Form 1.0 rendering `Coupled Reese` on MIDI note 29 at 172 BPM (`tf-render`).
- `pole-field.flac` — Pole Field 1.0 processing Tract Form’s bassline through `Neuro Chew` (14P Serial) with inter-stage Buchla ADAA2 drive, Morph X/Y sweep, and mono `Sub Lock`.
- `cutline.flac` — Cutline 1.0 rendering `Neuro Whip` at 172 BPM through its anti-aliased 8-voice PolyBLEP audition synth (`cutline-render`).
