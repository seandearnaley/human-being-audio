    Install notes

    macOS

    Signed and notarized, so Gatekeeper opens it without a fuss. The installer puts the VST3 and AU in /Library/Audio/Plug-Ins.

    Windows

    For the original unsigned Livecut ZIP, copy the .vst3 into C:\Program Files\Common Files\VST3, and check the SHA-256 first. For studio releases, run the signed installer listed for your product.

    Linux

    Studio Linux archives target Ubuntu 26.04 x86_64. Copy the complete VST3 bundle into ~/.vst3 and rescan in your host.

    Checking a download

    Every file's SHA-256 is under Details, next to the command that checks it. If they don't match, don't install it.

    How they're built

    I design them and tune them by ear. The code is written with AI assistance, then reviewed, tested and validated before every release. The source is on GitHub if you want to check.
