# Livecut Redux 2.0.2

Closing the editor on Windows now releases the renderer before its native parent window.

Livecut uses less memory when several instances are open. The grain resampler shares its read-only coefficients while each instance keeps its own captured audio. The editor exposes preset, history and mode controls to the keyboard. Screen readers can adjust Pad/Classic, Hold, Straight and Quantize. Each phrase dragged into an arrangement gets its own WAV file.
