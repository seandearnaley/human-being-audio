# Cutline 3.0.2

Closing the editor on Windows now releases the renderer before its native parent window.

Cutline’s XY pad controller assignment now appears as “XY to CC” in the editor and host parameter list. This lets Ardour for Windows load the VST3. Existing Cutline 3 sessions keep their pad assignments.

This release includes the three-layer step grid, four scenes, six PLAY programs, 46 patterns and 22 presets introduced in Cutline 3. Cutline 2 sessions open on the default beat.
