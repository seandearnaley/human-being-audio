# Datum 1.0.2

Windows now releases graphics resources used for font glyphs before the workstation unloads the plug-in.

Closing the editor on Windows now releases the renderer before its native parent window.

Initial flagship release of **Datum** — Human Being Audio's dedicated phase-locked neurofunk kick drum synthesizer.

## Highlights
- Four Nord-philosophy pure-DSP kick cores (`Sine`, `Twin-T`, `Harmonic` with Schroeder/Peak-Min crest optimization, and `Membrane` with Berger tension + Helmholtz cavity).
- Fixed-frame three-surface Visage UI (`SCULPT` | `ANATOMY` | `COMPOSE`) with direct-manipulation Pitch and Amplitude splines overlaid on live phase-separated Sub/Body/Click/Sum waveforms, log-Hz FFT, and Sub-Link sidechain scope.
- `Sub-Link` optional stereo sidechain input (`Vst::kAux` / AU `aumu`) with live correlation metering, YIN fundamental root detector, and one-click `Match Phase` / `Tune Root`.
- Four-slot Kit Matrix (`A/B/C/D`), 16/32-step Context Sequencer with ratchets and Reference Sub-Bass, sample-0 16x `.wav` drag, and 960-PPQ `.mid` drag.
- 32 curated factory presets across Neurofunk, Analog Twin-T, Halftime & UKG, Techno & Industrial, and Acoustic & Reference.
