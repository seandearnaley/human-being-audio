# Torus Glide 2.0.2

Windows now releases graphics resources used for font glyphs before the workstation unloads the plug-in.

Closing the editor on Windows now releases the renderer before its native parent window. This also applies when removing the instrument or closing a project with its editor open.

This candidate includes the PLAY and STUDIO views, six pitch worlds and five-voice MPE MIDI export introduced in Torus Glide 2.
