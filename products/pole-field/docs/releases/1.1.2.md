# Pole Field 1.1.2

Windows now releases graphics resources used for font glyphs before the workstation unloads the plug-in.

Closing the editor on Windows now releases the renderer before its native parent window.

Unified studio modulation engine with Free Hz LFOs, MIDI-retriggered timing modes, and phase-locked follower ratios.

## Highlights

- **Five Movement Timing Modes**: Every movement lane now supports `Sync` (host PPQ), `Retrig` (MIDI-retriggered host tempo), `1-Shot` (MIDI-triggered single sweep), `Free` (continuous sample-accurate Hz clock from `0.05`–`20 Hz`), and `Free R` (MIDI-retriggered Hz clock).
- **Phase-Locked Linked Free LFOs**: Setting a follower lane to `Follow` a `Free` or `Free R` leader automatically inherits the leader's Hz clock domain and scales its cycle frequency accurately by the `Ratio` chip (`÷4` through `×4`), keeping polyrhythmic Z-plane orbits phase-locked across any BPM or transport jump.
- **Unified Envelope + Free UI**: The shared `StudioMovementPanel` cleanly switches each lane between tempo rates, magenta-tinted Free Hz controls, follower ratios, and cyan Envelope Follower Attack/Release controls with zero clutter.
- **New Free-Hz Factory Presets**: Added *Free Drift Choir*, *Async Neuro Chew*, *Ocean Phase Halo*, and *Free Retrig Snarl* showcasing linked asynchronous Z-plane modulation alongside the Envelope Follower.
