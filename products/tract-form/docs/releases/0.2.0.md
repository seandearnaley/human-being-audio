## Tract Form 0.2.0

- The studio release packages the monophonic reese bass synth with 28 factory presets, eight macros, four tempo-locked movement lanes and offline resampling.
- The host lists Human Being Audio as publisher. Use About in the synth's top bar for the version, licence and source. Existing sessions keep the same synth identifiers.
- The universal Mac installer contains AU, VST3 and standalone. The signed Windows x64 installer and Ubuntu 26.04 x86_64 archive contain VST3 and standalone.
