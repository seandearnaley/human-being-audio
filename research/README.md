# Audio research

[The gain study](gain/) is a working example that builds and drives both production engines offline. Developers can run it without signing credentials or a DAW.

For a new experiment, record the sonic question, stimulus, parameter settings, sample rates, block sizes and acceptance measurement next to the renderer. Retain the reference source commit and permitted provenance of any recorded audio. A product can consume a validated operation from `modules/dsp`; keep the original experiment reproducible and add the smallest regression test to the product's ordinary suite. Instrument-specific voicing, presets and effect-specific timing continue to live with their products.
